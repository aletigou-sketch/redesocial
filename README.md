# Hi You!

Fundação de uma plataforma social brasileira, modular e responsiva.

## Stack

- React
- TypeScript em modo estrito
- Vite
- CSS com Design System próprio

## Scripts

- `dev`: ambiente de desenvolvimento
- `build`: typecheck e build de produção
- `typecheck`: validação de tipos
- `lint`: análise estática

Consulte `docs/ARCHITECTURE.md` para decisões arquiteturais, limites da etapa inicial e próximos passos.
